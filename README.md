# Crayon Split Diary · 原作里的小小世界

将照片或儿童画制作成上下分屏的动态纪念卡：上方保留用户原图，下方是奶油纸留白中的居中且四周留白的小幅儿童蜡笔涂鸦，再将**完整拼贴图交给 AI 视频模型**，让下方主体按自然逻辑运动。

## 状态

v3.1：静态拼贴与动作提示规则已整理，提供商无关的视频适配接口已预留。

**尚未接通视频生成服务。** GPT、抖音 AI 创作、豆包是可配置的适配器别名，不代表已有可用集成或任何账号必然支持图生视频。默认适配器不会联网、上传、计费或伪造视频。

## 使用

把本仓库克隆到支持 Agent Skills 的工具所使用的技能目录，目录名称保留为 `crayon-split-diary`。也可直接让你的 AI 助手读取 [SKILL.md](SKILL.md)，然后提供一张照片或儿童画。

示例请求：

> 使用 crayon-split-diary，把这张照片做成上下拼贴图，下方主体用简单潦草、笨拙可爱的儿童蜡笔涂鸦表现，再通过已连接的视频工具让它自然运动。

默认保留原图像素，奶油纸下屏以居中小主体和四周大留白构成。照片转成简单潦草、笨拙可爱的涂鸦；儿童画保留原有笔迹与错误比例，不精修。蝴蝶扇翅、猫咪抬爪、狗摇尾、花朵舒展等动作由模型依据实际姿态选择。不做分镜、抽帧、sprite sheet、关键帧或代码驱动的主体动画。

## 接入视频工具

参阅 [video-adapter.md](video-adapter.md)。支持工具／连接器、官方 API、网页或人工交接四种接入方式。接入时需核实真实图生视频能力、上传权限与费用；认证信息不得写入仓库。

`video_adapter.py` 定义能力、请求、任务、下载结果与适配器协议。`UnconfiguredAdapter` 始终明确报告尚未连接。

可以先在本地准备请求（Python 3.9+，无需第三方依赖）：

```bash
python3 prepare_video_request.py \
  --provider doubao \
  --collage /path/to/collage.png \
  --prompt-file /path/to/motion-prompt.txt \
  --output /path/to/video-request.json
```

此命令只创建请求 JSON，不生成视频。图片路径不会自动上传给远程服务。没有已接通工具时，交付拼贴图、动作提示词和待提交请求，不回退为代码动画。

## 文件

- `SKILL.md`：技能入口与完整流程。
- `art-direction.md`：画风、构图与文字规则。
- `natural-motion.md`：主体识别与自然运动提示词。
- `video-adapter.md`：视频接入约定和生命周期。
- `video_adapter.py`：提供商无关的 Python 协议及未配置实现。
- `prepare_video_request.py`：离线请求打包工具。

协议和请求打包经过本地测试；未验证任何提供商端到端视频生成。视频结果仍需完整播放检查上方照片、纸底和文字是否稳定。
